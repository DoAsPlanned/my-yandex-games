# 🏗️ Башня Ритма

> Аркадная игра на точность и тайминг — для платформы [Яндекс Игры](https://yandex.ru/games/).

**Статус:** ✅ v1.0.0 · **Ориентация:** Portrait · **Автор:** DoAsPlanned

## 📝 Об игре

Башня Ритма — казуальная аркада про реакцию, точность и чувство ритма. Вовремя нажимай, чтобы ставить движущиеся платформы ровно друг на друга и строить башню как можно выше.

Если блок установлен неидеально — выступающая часть срезается, следующая платформа становится уже. Каждая ошибка усложняет задачу.

## 🎮 Как играть

- **Нажатие** мышью, **пробел** или **тап** — поставить платформу
- Платформы двигаются по очереди по двум осям
- Чем точнее ставишь — тем шире и устойчивее башня
- Игра заканчивается при полном промахе

**Цель:** набрать максимум очков, побить рекорд, подняться в глобальном рейтинге.

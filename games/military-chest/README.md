# ⚔️ Боевые шахматы

> Пошаговая военная стратегия для двух игроков на клетчатом поле 10×10 — для платформы [Яндекс Игры](https://yandex.ru/games/).

**Статус:** ✅ v1.0.0 · **Ориентация:** Landscape · **Автор:** DoAsPlanned

## 📝 Об игре

Военная настольная стратегия, где два игрока управляют армиями: пехота, танки, самолёты, ракеты, пушки и вышки. Цель — уничтожить штаб противника.

Фигуры расставляются на поле 10×10. Игроки поочерёдно бросают кубик (1–6) и либо перемещают фигуру, либо стреляют. У каждой фигуры свои характеристики: направление движения, дальность стрельбы, урон.

## 🎮 Правила

1. **Игроки:** 2 (возможны коалиции 3–4 на поле 20×20, 5–6 на 30×30)
2. **Расстановка:** пехота и техника на первые две линии. Штаб — на клетке своего цвета
3. **Первый ход:** по броску кубика — у кого больше
4. **Ход:** кубик 1–6. Либо перемещение, либо стрельба
5. **Перемещение:** на число клеток с кубика в одном направлении по правилам фигуры
6. **Стрельба:** в любом направлении на число клеток с кубика. Крайняя цифра — на фигуру противника
7. **Урон:** по ТТХ фигуры. Уничтоженная фигура убирается, раненая теряет части
8. **Победа:** уничтожить штаб противника (10 очков урона)

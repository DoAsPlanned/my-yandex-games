# 🎮 My Yandex Games

Коллекция игр, разработанных для платформы [Яндекс Игры](https://yandex.ru/games/).

![Games](https://img.shields.io/badge/games-3-blue)
![License](https://img.shields.io/badge/license-MIT-green)

## 🕹️ Игры

| Игра | Описание | Ориентация | Версия |
|------|----------|------------|--------|
| [🃏 Пасьянс Косынка 2026](./games/solitaire) | Уютный пасьянс с 3 уровнями сложности, рейтингом и облачными сохранениями | Landscape | v1.0.0 |
| [🏗️ Башня Ритма](./games/tower) | Казуальная аркада на точность и тайминг: строй башню как можно выше | Portrait | v1.0.0 |
| [⚔️ Боевые шахматы](./games/military-chest) | Пошаговая военная стратегия 10×10: пехота, танки, самолёты, ракеты | Landscape | v1.0.0 |

## 📁 Структура

```
my-yandex-games/
├── games/
│   ├── solitaire/         # Пасьянс Косынка 2026
│   ├── tower/             # Башня Ритма
│   └── military-chest/    # Боевые шахматы
└── README.md
```

## 🚀 Запуск игры локально

```bash
cd games/solitaire   # или games/tower, games/military-chest
npx serve .
```
